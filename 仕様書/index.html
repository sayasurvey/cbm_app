1. プロジェクト概要

Next.js 15とReact 19を使用したモダンな書籍管理アプリケーションです。ユーザー認証、書籍の貸出・返却、ウィッシュリスト機能などを提供します。

主な特徴

  • Cookie/JWT認証による安全なユーザー管理
  • 書籍の貸出・返却システム
  • ウィッシュリスト機能
  • ページネーション対応の書籍一覧
  • レスポンシブデザイン
  • TypeScript完全対応
  • Storybook統合

6. 認証システム

認証フロー

  1. ユーザー登録: /users/registerでアカウント作成
  2. ログイン: /loginでメール・パスワード認証
  3. JWT発行: サーバーからJWTトークンを取得
  4. Cookie保存: トークンをCookieに格納
  5. ユーザー情報保存: ユーザー情報をlocalStorageに保存
  6. セッション管理: ミドルウェアでアクセス制御

保護されたルート

認証が必要なルート:
  • /books/* - 書籍関連ページ
  • /api/books/* - 書籍API

リダイレクト仕様

  • 未認証ユーザー → /login
  • 認証済みユーザー（ルートアクセス）→ /books
  • API 401エラー → /login

7. API仕様

認証API

エンドポイント メソッド 説明 認証
api/login POST ユーザーログイン 不要
api/register POST ユーザー登録 不要

書籍API

エンドポイント メソッド 説明 認証
api/books GET 書籍一覧取得 必要
api/books POST 書籍登録 必要
api/books/borrowed GET 借用書籍一覧 必要
api/books/wish-list GET ウィッシュリスト 必要

API通信仕様

  • ベースURL: NEXT_PUBLIC_API_URL環境変数
  • 認証ヘッダー: Authorization: Bearer {token}
  • エラーハンドリング: HTTPステータスコードに応じた処理
  • Cookie設定: credentials: 'include'

10. デプロイメント

Docker構成

  • ベースイメージ: Node.js 22.15.1 Alpine
  • ポート: 3000
  • Multi-stage build: 最適化されたイメージサイズ
  • Docker Compose: 開発環境統合

環境変数

  • NEXT_PUBLIC_API_URL: APIベースURL
  • NODE_ENV: 実行環境（development/production）

デプロイメント手順

  1. npm run build - アプリケーションビルド
  2. docker build -t book-management . - Dockerイメージ作成
  3. docker-compose up - サービス起動
  4. ポート3000でアクセス可能
